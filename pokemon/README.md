# Pokémon Champions 本地图标与种族值

## 当前版本与自动更新

2026-09-10 已切换为版本化资料包：**231 种、398 个形态条目、782 张 PNG**；391 个形态普通／闪光图标齐全，7 个待补。394 个条目取得 OP.GG 对应属性；飘浮泡泡的三种天气形态及莫鲁贝可空腹花纹继续保留旧资料，不用普通形态属性冒充。

有效版本以 `current.json` 为准，新单体 JSON／PNG 位于 `_versions/<包ID>/<宝可梦名字>/`；根 `index.json` 是带真实路径的兼容索引，原平铺目录及 `validation.json` 为历史原件。更新／校验／回滚方法见 [自动更新说明](../docs/data-updates.md)，具体运行证据见 [验证记录](../docs/validation/data-updates.md)。

当前新增资料来自 OP.GG，图标来自百科主列表和公开文件库；不含模式使用率。以下内容记录 2026-09-08 的历史采集过程与口径，不代表当前包计数或字段来源。

## 2026-09-08 历史采集

采集日期：2026-09-08。范围为 [52Poké《宝可梦列表（Champions）》](https://wiki.52poke.com/zh-hant/宝可梦列表（Champions）) 的主列表，未包含“还未登场的宝可梦”。

- **209 种宝可梦，361 个条目（含形态），722 张 PNG 图标。**
- 每个条目都有普通、闪光两个版本，均为原始 **128 × 128** PNG；未缩放、抠图或转码。
- 六项种族值全部有值：359 个条目使用 PokéChamp DB，2 个条目经用户允许使用 52Poké 补齐。
- 名称优先使用 [PokéChamp DB 简体中文版](https://pokechamdb.com/zh-Hans?format=double&season=M-5&view=pokemon) 的中文名，包括该站使用的“谜拟Ｑ”“流氓熊猫”“死神板”“仆斩将军”等写法。
- 不同形态独立存放；站点没有独立中文形态名时，添加百科简体形态后缀。超级进化使用“超级 + 简体种名 + X/Y/Z”。巴布土拨在数据站缺失，名称取百科简体版。

## 目录与字段

```text
pokemon/
  妙蛙花/
    妙蛙花.png
    妙蛙花_闪光.png
    妙蛙花.json
  超级妙蛙花/
    超级妙蛙花.png
    超级妙蛙花_闪光.png
    超级妙蛙花.json
  …
  index.json        # 全量索引，也包含每个条目的完整数据
  validation.json   # 文件、图片尺寸、来源与完整性校验结果
  _sources/         # 原始页面、站点名称表、原始列表、下载报告等
```

每个 JSON 的 `base_stats` 含 `hp`（HP）、`attack`（攻击）、`defense`（防御）、`special_attack`（特攻）、`special_defense`（特防）、`speed`（速度）；`base_stat_total` 为六项之和。

`images` 中记录图标来源、原始文件名、尺寸、文件大小和 SHA-256。`stats_source` 指向原始数据页面、本地存档及提取位置。`wiki_name` 保留百科命名，方便对照两站差异。

数据以双打项目为使用背景，参考赛季 M-5。**种族值本身不随单打/双打或普通/闪光变化，也不是对战中的实际速度。** 本次没有导出招式、道具、特性、使用率或个人队伍配置，也没有创建数据库；调研保存的原始网页可能包含这些站点原文。

## 形态对应与补充来源

地区形态、超级进化、幽尾玄鱼雄雌、南瓜怪人体型、洛托姆形态、海豚侠变身等分别匹配数据站对应的记录。

有 58 个外观/花纹等形态条目共用数据站的种级种族值，包括彩粉蝶花纹、多丽米亚造型、霜奶仙口味等；这些是显式形态映射，标为 `stats_mapping: shared_species_profile`，数据站并没有为每个外观独立列出六项值。该映射只适用于种族值，不能用于判断图标可区分性，也不能用于复用个人队伍配置。

经用户明确同意，以下两项使用百科补齐，并分别标记 `stats_source.provider: 52poke`：

| 条目 | HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 | 来源 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| 巴布土拨 | 70 | 115 | 70 | 70 | 60 | 105 | 490 | [百科种族值](https://wiki.52poke.com/zh-hans/巴布土拨#种族值) |
| 坚盾剑怪（刀剑形态） | 60 | 140 | 50 | 140 | 50 | 60 | 500 | [百科种族值，第八世代起](https://wiki.52poke.com/zh-hans/坚盾剑怪#种族值) |

图标存在来源重复：怖思壶的赝品/真品、来悲粗茶的凡作/杰作在列表中各自共用同一对图片。因此 722 个文件对应 718 个不同图片 URL；程序不能单凭这些相同图标分辨这两组形态。

## 复现与校验

项目根目录运行，依赖当前环境已有的 `requests`、`beautifulsoup4`、`Pillow`、`json5`：

```powershell
python -X utf8 scripts/collect_pokemon.py
python -X utf8 scripts/export_pokemon.py
```

采集脚本会复用已有页面和有效图片，限制每站并发数，失败时重试；下载报告在 `_sources/collection-report.json`。导出脚本不访问网络，从已保存页面重新提取数据，核对全部图片 SHA-256、PNG 格式、六项数值及总和，并更新 `validation.json`。名称表与两项百科补充页面使用本次保存的来源快照；若要更新至未来赛季，需要重新获取来源快照并复核新增形态映射。

这些是本地可行性验证素材；保留原站来源信息。图像和角色权利归各自权利方所有。
