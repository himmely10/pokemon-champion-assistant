# Pokémon Champion Assistant v0.4.0 Windows 候选版

v0.4.0 的目标是在现有单窗口 Champion Lab 的「队伍仓库」恢复**我方队伍截图导入**。这是候选版说明；功能是否完成及安装包是否可用，以对应版本的测试、冻结自检和隔离安装／升级证据为准，不以本文代替验收。

## 本版范围

- 「队伍仓库」在空仓库和已有队伍时均提供导入入口。
- 能力页、状态页分别接受本地图片或 OBS 当前画面，顺序不限，来源可混用；导入时预览原图和离线 OCR 识别结果。
- 使用者逐页核对并可修正队伍代码和六个成员身份；两页代码或成员不一致时拒绝合并，不写入队伍库。
- 合并结果先进入**未保存的新队伍草稿**。纠正身份后，原身份推断出的特性和招式须重新确认。只有使用者点击「保存队伍」后才写入个人队伍库；导入不能覆盖当前已保存队伍。
- 保留原有对手截图识别、伤害计算、资料库及本地队伍编辑流程；不引入新的在线队伍查询或其他截图版式支持。

## 安全与数据边界

截图只供当前请求识别和本机预览；不把原图、文件路径或 OBS 密码写进队伍资料和 API 返回值。OBS 密码继续使用当前 Windows 用户的加密保存机制。识别与合并均不自动保存队伍；替换图片或取消导入不得让过期识别结果覆盖新草稿。
