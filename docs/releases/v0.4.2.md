# Pokémon Champion Assistant v0.4.2 Windows 候选版

本版本在 v0.4.1 网页桌面界面基础上完善伤害结果的战术信息与可读性。

- 伤害超过 100% 时将范围限制在伤害轨道内，并用终点标记表示溢出，不再覆盖命中与先制度列。
- 乱数击杀根据伤害档位和目标当前 HP 显示命中后的实际击杀概率；命中率仍独立展示。
- 伤害列表右侧箭头可展开或收起对应招式详情，显示 HP 伤害、击杀概率、命中、先制、目标 HP 和场况判定。
- 修正安装版从安装目录之外启动时，Qt 运行库可能无法定位 `shiboken6` 的问题。
- 增加伤害条边界、乱数击杀概率与后端档位概率测试。
