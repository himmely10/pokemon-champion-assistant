# Pokémon Champion Assistant v0.4.1 源码更新

本版本保存 v0.4.0 之后的网页界面改进，不包含新的 Windows 安装包，也不表示 v0.4.0 候选版的安装、签名和干净系统验收门禁已经完成。

- 队伍仓库的可编辑队伍名称居中，保存状态和操作按钮分列两侧；窄窗口下名称独占一行。
- 资料库不再受默认 30 条搜索上限约束，按批次显示本地资料包中全部可独立选择的宝可梦身份，并延迟加载目录立绘。当前资料包为 398 条原始形态记录，其中部分花纹等外观共用对战身份，资料库目录为 378 条；没有新增资料包之外的宝可梦。
- 资料库目录和详情分别滚动；窄窗口下目录横向滚动、详情纵向滚动。切换宝可梦时不会短暂显示前一只的资料。

验证：前端测试、lint、生产构建和 Web 接口测试通过。此版本只发布源码，不生成或上传安装包。
