# v0.1.0 · 首个版本

Pokemon Champion Assistant 的第一个可运行桌面版本，面向 Windows 上的 Pokémon Champions 双打辅助。

## 功能

- 拖入选队截图，或连接 OBS WebSocket 截取 Switch 画面，识别右侧六只对手并显示简体中文名称。
- 展示属性、弱点／抵抗／免疫、普通与 Mega 种族值、速度参考线和招式资料。
- 招式按双打采用率排序，展示属性、威力、命中率与详细说明。
- 按队伍保存培养点、性格、特性、道具和四招，支持重命名、复制及截图 OCR 导入草稿。
- 自动计算双向伤害：我方四招打对手、对手常用伤害招式打我方；分别比较基础配置与常用培养点分配。
- 支持 Mega 计算形态、沙奈朵复制特性手选、场况调整及逐情景随机伤害范围。
- 伤害界面支持分配悬浮说明、可拖动详情区、80%–200% 缩放、最大化和 F11 全屏。
- 提供资料及采用率更新脚本；软件运行时每日检查采用率，无需 Codex 自动化。

## 安装

按仓库首页的“首次安装”操作。需要 CPython 3.13、Node.js 22+；OCR 为可选本地依赖。这个版本发布源码和资料快照，尚未提供独立 EXE 安装包。

## 当前范围

- 当前选队识别针对固定布局的对手阵容；我方伤害以用户选中的预存队伍为准。
- OCR 导入结果需要核对。不同队伍中的同种宝可梦配置独立，保留整队匹配规则。
- 伤害结果基于明确场况和独立对手假设，不等于完整回合模拟；部分多段、战斗历史及特殊机制会明确提示暂不可计算。
- 统计采用率不代表培养点、性格、特性和道具的联合概率。

详细说明见仓库中的 OBS、队伍配置、截图导入及双向伤害计算使用指南。
