# Pokémon Champion Assistant v0.2.1

v0.2.1 是首个公开的 v0.2 桌面安装版本，重点完善对战中的速度与双向伤害判断，并修复多个形态和配置无法计算的问题。

## 对战辅助

- 伤害页直接使用主界面选定的预存队伍，并在六个已识别对手之间切换。
- 场况、能力等级、顺风和条件特性集中在结果上方；完整情景编辑和计算详情分别保留独立页面。
- 支持帮助、反射壁、光墙、极光幕、友情防守，以及攻击、防御、特攻、特防和速度等级。
- 补充猛火、激流、茂盛、虫之预感、轻装和电力转换等条件状态。
- 补充波导防护、毛皮大衣、硬爪、飞行皮肤等减伤与增伤特性，并在详情中说明实际生效条件。
- 多次命中招式显示单次伤害及 2–5 次总范围。

## 普通与 Mega 形态

- 修复喷火龙 X/Y、超级路卡利欧、超级路卡利欧 Z、超级暴飞龙等形态的伤害计算与招式展示。
- 本次计算切换 Mega 分支时自动采用对应进化石，不修改预存队伍。
- Mega 形态缺少独立统计时，沿用普通形态的双打招式采用率、常用培养点分配和性格；伤害仍使用 Mega 自己的种族值、属性与固定特性。
- 修复地区形态、性别形态和部分特殊形态在伤害引擎中的名称映射。

## 识别与交互

- 对手截图识别改进边缘图标处理，补充巨钳螳螂等真实截图回归。
- 己方能力页和状态页均可从文件或 OBS 截图导入，并在保存前核对六名成员。
- 队伍保存、OBS 连接和识别完成后提供明确反馈；无法计算时在表格和状态栏显示具体原因。
- 对手特性选项只显示当前宝可梦可能拥有的特性。

## 安装说明

下载 `PokemonChampionAssistant-0.2.1-windows-x64-Setup.exe` 并运行。安装包暂未进行代码签名，Windows 可能显示未知发布者提示。个人队伍和 OBS 设置保存在安装目录之外，覆盖安装时会保留。

完整测试、冻结程序自检、安装包大小和 SHA-256 记录见 [Windows 打包验证记录](../validation/packaging.md)。
