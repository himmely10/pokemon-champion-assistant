# Pokémon Champion Assistant v0.3.0 Web Preview

v0.3.0 将 Champion Lab 网页版接入现有本地资料、队伍、截图识别、OBS 与伤害规则服务，并继续保留桌面入口。网页版只监听本机回环地址，不是可脱离 Python 服务运行的静态演示页。

## 网页版

- 按产品化设计系统实现对战台、队伍仓库、伤害计算、资料库与设置页面。
- 对战台支持预存队伍、上传选队截图和从 OBS 截取当前画面。
- 伤害页支持双方宝可梦与战斗形态切换、属性相性、双向招式伤害、命中率、先制度与固定我方实配速度线；两个计算方向均可切换 3 个基准配置与 3 个常用分配，常用分配速度会并入对手速度参考并按速度降序展示。
- 场况设置覆盖天气、场地、要害、双方特性触发、异常状态、能力等级、倒下同伴、帮助、双墙、极光幕、守住、友情防守与顺风。
- 基础种族与 Mega 形态分层展示，修复水箭龟被形态列表挤出的选择错误。
- OBS 密码验证成功后使用 Windows DPAPI 按当前用户加密保存；空密码输入不会覆盖已保存凭据。

## HP 输入协议

- 网页与桌面伤害页统一使用 HP 百分比，范围为 1–100，默认 `100` 表示满 HP。
- 规则适配层按每只宝可梦的实际最大 HP 换算当前 HP，保证满血和低血量特性判断一致。
- 移除旧版 `0` 代表满 HP 的隐式约定，避免输入框初始值被误解为濒死状态。

## 桌面与工程化

- 桌面程序增加产品化导航壳层、深浅主题与设置中心，并修复深色主题下表格文字对比度。
- 新增本地网页启动入口、API 契约测试和正式测试收集边界。
- 网页生产构建继续输出到忽略目录；发布代码包含源码、设计系统与构建配置，不提交依赖目录和本地产物。

## 验证范围

- 完整 Python/Qt 测试套件。
- TypeScript 类型检查、前端 lint 与 Vite 生产构建。
- 本地浏览器检查主要页面、伤害形态切换、HP 默认值与控制台错误。

该版本先以 Web Preview 源码与 PR 形式发布。Windows v0.3.0 安装器仍需通过候选构建、冻结诊断和干净 Windows 验收后再发布。
