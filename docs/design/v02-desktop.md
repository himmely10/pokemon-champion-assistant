# v0.2 桌面视觉与首次使用

采用深蓝导航、浅色资料卡片、青色主操作，保持属性颜色和简体名称。
主导航固定提供对战资料、队伍配置、双向伤害、资料更新与使用引导；操作状态单独呈现，更新不会混入已显示的分析版本。

## 原型与自查

实现前生成并查看了四张原型：

- `artifacts/design/v02/prototype-主页.png`
- `artifacts/design/v02/prototype-队伍.png`
- `artifacts/design/v02/prototype-伤害.png`
- `artifacts/design/v02/prototype-更新.png`

这些是排版原型，示例数值并非伤害计算结论。原型选择清楚的卡片层级与底部主操作；现有独立队伍／伤害窗口继续保留，避免改变成熟计算流程。
主界面首次实截图审查发现标题因布局伸展而意外换行，已调整标题伸展及固定模式标签高度。

## 已实现

- `ui/theme.py` 统一字体、卡片、按钮、选项卡、键盘焦点及状态样式；应用和子窗口共用。
- 主界面独立导航；原创应用图标来自 `assets/branding/app.ico`。
- 主界面按工作区限制初始尺寸；小窗口允许外层滚动，资料卡片和左右面板继续独立滚动，不通过缩小字体隐藏内容。
- 对话框保留最大化；伤害全屏、缩放、详情分隔条及队伍固定保存区继续沿用。
- 首次引导允许跳过、重开。图片路线不依赖 OBS；OBS 路线说明服务启用、地址／端口／密码和来源选择。
- 空来源给出添加视频采集设备的下一步，认证失败后仍可重新连接。密码不写入设置，保存 OBS 参数不覆盖更新及引导状态。
- 可选择旧项目目录，调用 `migrate_legacy` 导入队伍及设置，已存在的数据不覆盖。
- 截图输入区支持回车／空格键打开文件选择器。

## 验证边界

实界面截图保存在 `artifacts/design/v02/actual-*.png`，覆盖主界面和引导；小屏逻辑布局的额外截图记录在同目录。
1366×768 与 1920×1080 逻辑窗口以 Qt 离屏渲染检查；960×540、683×384 代表高缩放下可用空间压力，不等于已在真实 Windows 显示器切换系统 DPI 验证。
实际 Windows 100%／150%／200% 缩放、任务栏占用、多显示器迁移仍属于发行前实机门禁，应在记录实际结果后确认通过。
本轮不修改更新中心内部操作流程或 OCR 导入界面。
