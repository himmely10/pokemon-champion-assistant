# 对战操作与 OBS 队伍导入增补

继续完成 v0.2 原计划，同时实现 2026-09-13 用户提出的八项调整。

- 队伍导入同时支持本地能力／状态截图和从 OBS 分别取两页。新样本为 `图片/能力2.png`、`图片/状态2.png`，必须作为真实回归样本；输出仍需用户核对再保存。
- 主界面确认一支已保存队伍；伤害对照沿用该队伍。对手选择只在当前六个识别／手动修正槽位间切换，纠正身份留在主界面。
- 双方能力等级与速度状态放在便于访问的位置；招式附近显示己方实配速度和对手速度参考。支持速度等级、顺风及明确触发的轻装／天气加速等条件，不能默认假定已经触发。
- 培养表和 OCR 预览中的未知值明确指出字段；不把未知数值当成零。
- 电光束按明确的充能后特攻修正计算，避免与手动等级重复计入；普通多段招式分别展示每段和各命中次数情景。尚未验证的逐段变威力机制维持明确不可用提示。
- 沙奈朵、普通／Mega等现有功能保持。喷火龙 Y 配 X 石的冲突直接显示在形态旁；切换道具若仅为本次假设，必须清楚标注，不悄悄修改预存队伍。
- 先补现有安装包验收，再整合新改动重新构建。干净系统／公开渠道未完成前继续使用候选发行标记。

验收以真实图片回归、领域伤害／速度测试、UI 交互和实际截图审查为依据。
