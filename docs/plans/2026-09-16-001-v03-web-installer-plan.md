# v0.3.0 网页版 Windows 安装包计划

## 目标

将已接入现有资料、队伍、OBS、截图识别与伤害规则的 Champion Lab 网页版纳入 v0.3.0 Windows 安装包。普通用户安装后可从开始菜单直接打开网页版，无需自行安装 Python、Node.js、pnpm 或构建前端，同时保留原桌面入口。

## 实施决策

1. 候选构建先用锁定的 pnpm 安装前端依赖并运行 Vite 生产构建。
2. 打包构建器校验 `index.html` 及其引用的 JavaScript/CSS，将完整 `web/dist` 复制到冻结资源并写入哈希清单。
3. PyInstaller 由同一份代码产生三个入口：桌面程序、后台自检工具与带命令窗口的 `ChampionLabWeb.exe`。
4. Inno Setup 同时创建桌面程序和 Champion Lab Web 开始菜单入口，两个桌面快捷方式均保持可选。
5. 网页启动器只监听回环地址；重复启动时只复用通过 Champion Lab 服务标识验证的已有实例，其他程序占用同一端口时明确报错。

## 验证合同

- 资源单元测试覆盖网页入口、JS/CSS 缺失与清单完整性。
- 启动单元测试覆盖冻结 EXE 模式选择、单端口互斥与已有 Champion Lab 实例探测。
- 运行前端 lint、TypeScript 类型检查和生产构建。
- 运行完整 Python/Qt 测试套件，不改变既有测试结果。
- 构建冻结目录和 Setup，运行冻结自检、真实安装、快捷方式、HTTP/API、重复启动与卸载闭环。
- 记录安装包字节数和 SHA-256；在干净 Windows 11 VM、代码签名和公开稳定通道完成前保持 candidate 标记。

代码、单元测试、冻结构建、Setup 编译和开发机安装闭环已完成。对外公开发布仍受上述三项人工发行门禁约束。
