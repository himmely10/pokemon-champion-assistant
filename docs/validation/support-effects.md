# 辅助效果覆盖与验证

日期：2026-09-12。规则：仓库锁定的 Champions 引擎快照。仅计算本次直接伤害，不模拟整回合。

## 数据路径

`BattleEditor` 双方独立输入 → `battle_effects.engine_side` → `DamageService.jobs` 按攻击方向设置 attackerSide / defenderSide → Node `calc.Field` → 规则引擎。界面不乘伤害倍率。`battle_effects.SUPPORT_EFFECTS` 统一字段、标签、分组和提示；旧场况缺少新增极光幕字段时默认未启用。

Node 返回每个已选辅助效果的作用方和判定。只有引擎 `rawDesc` 记录的修正标为“本招适用”，作用方错误、墙种类不符、要害、穿透、拆墙、固定伤害等显示忽略原因。顺风标为速度条件输入，不保证一定改变本招伤害；通用早退等无法唯一解释的情况明确列出可能机制，不推断成已经生效。
