## 数据来源查询

公开 [Replica Team Viewer](https://champions.karthikb.dev/replica) 声明与 Pokémon 官方无关联。根据其页面公开表单，提交 `teamid` 做只读查询；HTTP 200 返回应用级 failure / 503，内容为服务修复中，不能查询新队伍。原始页面与响应在 `docs/research/2026-09-11-team-import/`。没有据此宣称官方 API 可用。

OCR 采用 [RapidOCR 官方文档](https://rapidai.github.io/RapidOCRDocs/main/en/install_usage/rapidocr/usage/) 的本地 Python 接口，依赖锁在 `requirements-ocr.txt`。
