# 桌面对战资料台

v0.3.0 起，桌面程序默认在一个原生窗口内承载 Champion Lab 网页工作台。对战、队伍、伤害计算、资料百科和设置通过左侧导航原位切换，不再打开独立业务窗口；深浅主题与网页版完全共用。

双击项目根目录的 `run_assistant.bat` 启动。把游戏图片作为命令行参数传入时仍会进入旧原生界面，作为兼容与诊断路径；普通用户无需使用该路径。
已配置的桌面环境为 `.venv-ui`，原来的 `.venv` 仍可运行命令行识别与资料更新。

安装版只应从开始菜单的 **Pokemon Champion Assistant** 启动。`ChampionWorker.exe` 是内部更新和自检组件，并非用户入口；正式构建会隐藏它自己创建的控制台窗口。

## 旧原生界面兼容说明

1. 把完整的 Champions **选队界面**图片拖入左侧预览区域，或点击「打开截图」。支持 PNG、JPG、WebP、BMP，一次一张。
2. 程序识别右侧六只对手，点击任意成员查看属性与种族值。原型使用固定 16:9 布局，带 OBS 控件、黑边或直播装饰的画面应先改为纯游戏源。
3. 普通与各 Mega 分支种族值并排；点击列标题切换资料预览，不修改对手的识别身份。形态属性也分别展示。
4. 招式分成「伤害招式」与「变化招式」，列表直接显示属性、分类、威力和命中率。悬浮显示说明，点击或用方向键选择后在右栏查看详情。搜索支持名称、属性和效果关键词。
5. 名称识别不确定时，选中对应槽位，用下方搜索选择宝可梦后点「修正槽位」。单纯「查看资料」不会改变对手队伍。新截图会撤下上一张的结果与手工修正。

小窗口可滚动左右资料区域及招式详情。程序在后台线程执行截图和识别；取消后等待当前请求结束，迟到结果不再显示。

软件启动时检查采用率缓存，满 24 小时在独立进程更新；持续运行每小时复查，成功后自动刷新列表。失败时使用原缓存，关闭软件停止更新，不依赖 Codex 定时任务。

## OBS 采集

在 OBS 的「工具 → WebSocket 服务器设置」中启用服务器。资料台点击「连接 OBS」，填入地址、端口和密码，然后「连接并读取采集源」。同机默认 `localhost:4455`，以 OBS 实际设置为准。

优先选择 Switch 对应的视频采集设备源，也支持包含纯游戏画面的场景。点击「使用此采集源」，回到主窗口按「从 OBS 截图并识别」。这一版按按钮采集一帧，不持续识别视频。

程序使用 OBS WebSocket v5 的 GetVersion、GetInputList、GetSceneList 和 GetSourceScreenshot，只读取信息与截图。连接失败时检查服务器开关、地址、端口和密码；截图布局错误时检查所选源。

主机、端口、源名称保存到 `config/local_ui.json`；密码仅保留在当前进程内，重启后需重新填写。该设置文件已加入忽略列表。最近一次成功识别的输入类型、源名称、资料版本和识别报告保存到 `artifacts/desktop/last_result.json`，不包含密码或图片。

## 资料范围

图标、属性、种族值及招式均离线读取，界面和识别器固定使用启动时解析到的同一个资料包。运行自动更新后重启界面即可使用新包。

`moves.json` 由 OP.GG 公开页面中的招式定义生成，包含属性、分类、威力、命中率、PP、先制度、目标与说明。来源标为不可用或被该宝可梦禁用的招式不展示。旧的已校验资料包如果只有原始 OP.GG 页面，也可离线解析招式。

展示来源标为可用的招式池，叠加独立获取的 OP.GG 当前赛季双打采用率。分组内先按采用率降序，未公布的招式按固定威力降序；页脚显示赛季和来源时间。统计与静态资料分开更新，详见 [采用率与速度线](usage-speed.md)。已支持预存队伍培养点配置与双向伤害计算，详见根目录使用指南。无固定威力显示「特殊」，没有数值命中率显示「—」并解释，缺字段显示「未知」；不把缺失值当作必中。

资料区默认显示 50 级六档速度线，可选其他宝可梦并排对比，也可切回普通／Mega 种族值对照。OBS 连接窗口支持「读取本机 OBS 设置」，连接失败会区分未启用、认证失败、超时与源请求失败；完整流程见根目录 [OBS 使用指南](../OBS使用指南.md)。

来悲粗茶与彩粉蝶仍按已确认的外观合并规则显示名称。缺少独立来源的形态不会借用其他形态的招式或 Mega 关联。

## 重新配置开发环境

使用独立的官方 CPython 3.13 创建虚拟环境。本机验证版本为 3.13.7，不使用 `--system-site-packages`。继承 Anaconda 系统包的环境在本机加载 Qt 时发生 DLL 冲突。

```powershell
py -3.13 -m venv .venv-ui
.\.venv-ui\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv-ui\Scripts\python.exe -X utf8 launch_assistant.py
.\.venv-ui\Scripts\python.exe -X utf8 launch_assistant.py "例子.png"
.\.venv-ui\Scripts\python.exe -m pytest -q
```

只运行界面时安装 `requirements-ui.txt` 即可。核心新增依赖固定为 PySide6 6.11.2、obsws-python 1.8.0；测试另使用 pytest-qt 4.5.0。尚未制作可脱离 Python 环境的安装包。

## 模块

| 位置 | 职责 |
|---|---|
| `champion_assistant/ui/main_window.py` | 资料台、槽位状态、人工修正、形态和招式详情 |
| `ui/worker.py` | 后台截图与识别，取消和结果信号 |
| `ui/obs_dialog.py`、`ui/widgets.py` | OBS 设置、拖入图片、属性标签 |
| `capture/obs.py` | OBS 只读协议调用、图片解码和错误处理 |
| `data/references.py` | 固定版本的资料仓库、Mega 关联、可用招式池 |
| `data/moves.py` | 招式解析、缺失值语义、统一说明格式 |
| `tests/test_desktop.py` | Qt 图片识别、资料交互、OBS 协议与密码保存边界 |
