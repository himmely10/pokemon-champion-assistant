# 双打招式采用率与速度线

## 招式排序

保留伤害招式、变化招式两组。每组内先按 **OP.GG 当前赛季双打采用率从高到低** 排序，有数据的 `0%` 也属于已公布数据。没有公布采用率的招式显示 `—`，排在后面，并按固定威力降序；无固定威力的招式最后按名称稳定排序。

采用率是来源的招式采用统计，不是对手下一回合使用该招式的概率，也不是本局已确认配招。来源只列出部分招式，未列出不能解释为 0%。变化招式没有威力时不伪造数值。

只读取公开接口明确返回的 `doubleDetail.moves`；不会混用单打、胜利招式、失败招式或上一赛季。赛季由 OP.GG 公开榜单自动发现，并在请求中显式指定。页脚显示赛季和来源更新时间。Mega 或其他形态没有独立统计时，不自动套用普通形态数据；只有来源明确声明合并身份时才标注合并统计。

首轮真实同步：M-6 双打，245 个统计身份，零失败。统计身份数与本地图标的物种数、形态数含义不同。

## 更新方式

双击根目录 `update_usage_data.bat` 可立即刷新。命令行：

```powershell
.\.venv-ui\Scripts\python.exe -X utf8 scripts/update_usage_data.py
# 完整同步未满 24 小时则跳过，适用于定时调用
.\.venv-ui\Scripts\python.exe -X utf8 scripts/update_usage_data.py --if-due
```

**更新由软件自身触发，不依赖 Codex。** 之前误建的 Codex 定时任务已关闭。当前软件没有账号系统，以启动软件作为检查时机：

1. 启动后在独立后台进程调用同一份脚本，传入 `--if-due`。没有缓存或距上次完整成功同步已满 24 小时才联网同步，未到期直接使用缓存。
2. 软件持续运行时，每小时复查一次到期状态；失败或部分失败在后续复查时重试，不把失败当作完整成功更新时间。
3. 更新成功后自动刷新当前招式列表，保留对手身份、查询内容和资料上下文；更新不占用 OBS／识别工作线程。
4. 软件关闭后停止检查与正在运行的更新进程，已发布快照保留；下次打开再按更新时间判断。没有软件外部的常驻任务。

按本地资料目录共用更新时间与文件锁，重复打开和多个实例不会并发同步同一份采用率。当前自动更新范围包括双打招式采用率、培养点分配及性格采用率。培养点和性格是独立统计，不生成联合配置权重。每天更新能控制缓存时效，不保证来源变动立即同步，断网时仍显示带时间的缓存。

软件内更新完成自动生效；通过批处理更新后，可点击资料台「载入最新采用率」，无需重新识别图片。新物种、图标和招式定义仍由 `update_pokemon_data.bat` 更新。

数据保存到 `pokemon/_usage/`：

- `current.json`：原子切换的快照指针。
- `snapshots/usage-*.json`：按内容校验的不可变快照，记录模式、赛季、各身份的更新时间和采用率。
- `cache/`：公开入口发现缓存和按查询保存的最新压缩响应。

入口标识从网页公开脚本自动发现，避免写死随网站部署变化的标识。最多 3 个请求并行，设超时和有限重试。单项失败保留**同赛季**旧值并标注；失败超过 20% 时不替换快照。赛季切换时不引用上赛季缺失项，超过 48 小时的缓存会显示更新提示。退出码：0 成功或未到期，2 部分失败，1 失败。

## 速度线

资料区默认打开「速度线 · 50级」，也可切回「种族值对照」。普通形态与 Mega 分支并排；通过「加入速度对比」可再选一只宝可梦或具体形态。

| 档位 | 参考条件 |
|---|---|
| 极速围巾 | 32 点速度培养点、加速性格、讲究围巾 |
| 极速 | 32 点速度培养点、加速性格 |
| 满速围巾 | 32 点速度培养点、中性性格、讲究围巾 |
| 满速 | 32 点速度培养点、中性性格 |
| 无投 | 0 点速度培养点、中性性格 |
| 下降 | 0 点速度培养点、减速性格 |

采用与用户参考站一致的 50 级参考计算：`floor((速度种族值 + 20 + 速度培养点) × 性格修正)`，性格修正为 1.1、1.0、0.9。讲究围巾在此结果上乘 1.5 后再次向下取整，代码使用整数运算。

大狃拉种族速度 120 的六档结果依次为 **283、189、258、172、140、126**，与用户上传截图一致。公式与档位核对来源：[PokéChamp DB 大狃拉](https://pokechamdb.com/zh-Hans/pokemon/sneasler?season=M-6&format=double)，公开前端核验快照在 `docs/research/2026-09-11-usage-speed/`。

“下降”是减速性格，不是战斗中速度降低一级。这些是参考配置，尚未计算轻装、顺风、天气、麻痹、能力等级、戏法空间或招式先制度，也不代表已知对手实际速度。我方整队培养配置和完整速度／伤害情景将在下一阶段接入。
