# Champion Lab 本地网页版

## 打开方式

1. 确保 `web/dist/index.html` 已由 `pnpm build` 生成。
2. 双击项目根目录的 `run_web.bat`。
3. 浏览器会打开 `http://127.0.0.1:32145`。关闭命令窗口即可停止服务。

网页依赖本地 Python 进程提供资料与计算能力，因此不能直接双击 `index.html` 使用，也不应把 `web/dist` 上传到静态托管网站。

## 已接通的功能

- 对战台：读取预存队伍；上传 16:9 选队截图或从 OBS 抓图，并调用原识别器。
- 队伍仓库：读取、创建、复制、编辑、保存和删除 SQLite 队伍；保存继续走 `TeamRules` 校验。
- 伤害计算：可切换队伍成员与双方战斗形态；把双方特性、条件触发、HP、异常、能力等级、倒下同伴、帮助、双墙、极光幕、守住、友情防守、顺风和全局场况传入原 `DamageService` 与内置 Node 规则引擎。结果同时展示双方属性相性、我方实配速度、对手参考速度线、实际命中与当前先制度。
- 资料库：检索本地 398 个形态，显示种族值、属性相性、招式采用率和形态家族。
- 设置：配置 OBS、测试截图，持久化主题与减少动态；验证成功后的密码使用 Windows DPAPI 按当前用户加密保存，后续连接可直接复用。

## 安全边界

- HTTP 服务只允许绑定 `127.0.0.1`、`localhost` 或 `::1`。
- 修改接口拒绝来自非本机网页来源的请求。
- OBS 密码不会进入普通设置 JSON、接口响应或诊断摘要；加密凭据只能由保存它的 Windows 用户解密。
- 图片上传限制为 25 MB、4000 万像素；JSON 请求限制为 2 MB。
- 宝可梦图标只能通过已验证资料目录和记录身份读取，不能传入任意文件路径。
