# 资料库页面规范

> 继承 `../MASTER.md`。资料库是探索型页面，不承担对战台的即时判断职责。

## 页面目标

通过一个统一搜索入口查看宝可梦、形态、属性、速度线和招式资料，并能将对象带入当前对局或
伤害计算。

## 布局

- 顶部固定搜索，标签为“搜索宝可梦或招式”，支持名称、属性和效果关键词。
- 左侧为结果列表，中央为对象详情，右侧只在宽屏显示“加入当前对位”等上下文操作。
- 无搜索词时显示最近查看、当前对局成员和常用宝可梦，不显示空白表格。
- 宝可梦详情标签固定为“概览 / 速度 / 招式 / 形态”；不要把属性和种族值拆成过多卡片。

## 宝可梦概览

- 详情头显示 88px 图片、名称、全国图鉴编号、属性与形态选择器。
- 种族值优先使用横向条形对比；同时显示数值，条形不能代替文本。
- 普通和 Mega 形态只在用户明确选择时切换，不静默更改对战台识别身份。
- 属性克制按弱点、抵抗和免疫分组，倍率写在徽标旁。

## 速度页

- 默认展示 50 级六档速度线和当前资料说明。
- 用户添加比较对象后，使用并排数值或点图；不使用雷达图。
- 条件特性、顺风和能力等级作为可见条件 chip。
- “参考档位”与“实配速度”明确区分，避免用户误认为对手配置已知。

## 招式页

- 搜索和筛选保持在列表顶部，筛选项：伤害/变化、属性、分类、是否有采用率。
- 采用率用细条和百分比表达，不使用饼图。
- 招式详情顺序：效果 → 属性/分类 → 威力/命中/PP/先制度 → 目标 → 来源。
- 无固定威力显示“特殊”，无数值命中率显示“—”并解释，不写成“必中”。

## 搜索交互

- `Ctrl+K` 从任意页面打开全局搜索；Enter 打开首个结果，Esc 返回原页面。
- 搜索 150ms 防抖，结果数较大时使用过滤代理模型。
- 无结果提示：“没有找到‘巨金’之外的匹配？请检查名称或改用属性关键词。”实际文案根据
  搜索词生成，并提供清空筛选。
- 中文长名称允许两行显示；单行表格中省略时必须有可键盘触发的完整 tooltip。

## 对局上下文操作

- 有当前对局时可显示 `设为我方`、`设为对手` 或 `打开伤害计算`。
- 修改对手槽位必须二次明确对象和位置，普通“查看资料”永远不改写识别结果。
- 无当前对局时不隐藏操作，而是禁用并解释“开始对战分析后可加入对位”。

## 验收重点

- 搜索、查看资料和修正对手是三个可区分的动作。
- 表格和可视化不把缺失资料表现成零值。
- 从全局搜索返回后恢复原页面、焦点和滚动状态。
