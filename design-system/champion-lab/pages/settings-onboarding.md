# 设置与首次使用规范

> 继承 `../MASTER.md`。设置承载 OBS、资料更新、外观、诊断与关于；首次使用是独立引导流。

## 设置页结构

左侧二级导航：

1. 采集与 OBS
2. 资料更新
3. 外观与辅助功能
4. 存储与迁移
5. 诊断与关于

设置页不使用多个模态框串联。每个分区内的保存范围清晰；可立即生效的设置无需统一
“保存全部”。

## OBS 设置

- 地址、端口、密码和来源选择均有可见标签。
- 密码说明“只在本次运行使用，不写入设置文件”，并提供显示/隐藏按钮及粘贴支持。
- Primary 为 `连接并读取采集源`；连接成功后变为状态徽标，不继续强调按钮。
- 空来源说明在 OBS 中添加“视频采集设备”的下一步。
- 错误分别处理未启用、认证失败、超时和来源请求失败，并提供对应恢复行动。

## 资料更新

- 首层显示当前版本、资料生成时间、更新渠道和最近检查结果。
- Primary 为 `检查更新`；有可用更新时变为 `下载并安装资料`。
- 自动检查间隔使用单选或下拉，文案明确“仅软件运行时检查”。
- 更新完成说明“新资料将在下一次分析使用；当前已打开结果保留原版本”。
- 导入 ZIP、回滚和渠道配置归入高级操作；回滚需要确认目标版本。
- 下载、校验、切换版本是可读的阶段状态，不用一条无限进度条代替全部过程。

## 外观与辅助功能

- 主题：跟随系统 / 浅色 / 暗色。
- 动效：跟随系统 / 减少动态效果。
- 界面密度：舒适 / 紧凑；紧凑模式仍满足最小可操作尺寸。
- 字号：100% / 125% / 150%，切换后立即预览并允许恢复默认。
- 所有选项可通过键盘和屏幕阅读器操作，不能依赖拖动滑块才能设置准确值。

## 首次使用流程

首次使用只完成一件事：让用户成功开始第一次分析。

```text
欢迎 → 选择输入方式 → 可选配置队伍 → 第一次识别 → 完成
```

### 第 1 步：欢迎

- 标题：“准备好第一次对战分析”。
- 两句内说明本地截图、OBS 和离线资料能力。
- Primary 为 `从图片开始`，Secondary 为 `设置 OBS`。
- `暂时跳过` 是 Quiet 操作，位置稳定且可键盘访问。

### 第 2 步：输入方式

- 图片路径直接打开文件选择器，不要求阅读 OBS 指南。
- OBS 路径只收集必要字段，并在同页测试连接。
- 用户随时可以返回上一步；当前输入不会被清空。

### 第 3 步：我方队伍（可选）

- 清楚说明“不配置队伍也能识别和查资料，但无法使用实配伤害结果”。
- 提供 `选择已有队伍`、`截图导入` 和 `稍后配置`。

### 完成

- 直接进入对战台并保留刚才结果，不再弹成功消息框。
- 焦点放到第一个已识别对手或“打开截图”主按钮。

## 数据迁移

- 显示将读取的目录和数据类型，不默认覆盖现有数据。
- 冲突使用逐项选择或“保留现有 / 导入副本”，不提供含糊的“合并”。
- 完成后列出导入数量、跳过数量和查看详情入口。

## 诊断与隐私

- 清楚区分本地资料、OBS 密码、队伍数据和可导出的诊断信息。
- 复制诊断报告前预览将包含的字段，不包含 OBS 密码或截图原图。
- 关于页显示软件版本、资料版本、许可证和数据来源。

## 验收重点

- 不连接 OBS 的用户可以在两个主要操作内开始图片识别。
- 密码不落盘，并允许密码管理器或粘贴操作。
- 更新、迁移和回滚不会改变当前打开分析的资料快照。
- 引导可以跳过、返回和重新打开，不形成无法退出的模态流程。
