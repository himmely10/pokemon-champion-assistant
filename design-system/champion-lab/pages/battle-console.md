# 对战台页面规范

> 继承 `../MASTER.md`。本文件定义应用默认页及识别工作流。

## 页面目标

在一个连续上下文内完成：选择我方队伍 → 获取对手截图 → 确认六个位置 → 选择双方对位 →
查看即时判断 → 进入完整伤害计算。

## 信息优先级

1. 双方阵容与当前对位。
2. 速度、克制和危险招式结论。
3. 当前计算条件。
4. 完整速度线、招式和种族值资料。
5. 数据来源、更新时间和识别相似度。

## 宽屏布局（≥1440px）

```text
┌────────────────────────────────────────────────────────────────────┐
│ 对战台    本局队伍：顺风队 M6         OBS 已连接   重新识别   ··· │
├───────────────────────────────────────────────┬────────────────────┤
│ 我方  [1][2][3][4][5][6]                     │ 当前对位           │
│                    VS                         │ 大狃拉 vs 烈咬陆鲨 │
│ 对手  [1][2][3][4][5][6]                     │ 对手更快           │
│                                               │ 地面招式危险       │
│                                               │ [打开伤害计算]     │
├───────────────────────────────────────────────┴────────────────────┤
│ 对位结论 | 速度线 | 常用招式 | 属性与形态                          │
│ 当前标签页内容                                                     │
└────────────────────────────────────────────────────────────────────┘
```

- 页面标题栏高 56px；阵容舞台建议高 280–320px。
- 判断面板固定 320px，不能被表格挤压。
- 当前我方和对手槽位通过细线连接到中央 VS 轴；连接线不承担信息，只增强空间关系。
- `打开伤害计算` 是页面唯一 Primary 按钮。

## 紧凑布局

- 1120–1439px：导航收窄；阵容槽位图缩至 48px；判断面板 280px。
- 800–1119px：判断面板移到阵容板下方，结论以三列摘要呈现。
- 600–799px：我方和对手分别使用 3×2 槽位；当前对位卡位于双方阵容下方；二级标签页
  允许换行但不横向溢出。

## 页面状态

### 首次准备

- 舞台中央显示标题“开始一场对战分析”。
- 两个输入选择并列：`打开游戏截图` 为 Primary，`连接 OBS` 为 Secondary。
- 已存在预存队伍时先选择最近使用的队伍；不存在时显示 `创建我方队伍`。
- 不展示空表格和六档速度线。

### 正在识别

- 保留已选我方队伍，六个对手槽位依次显示扫描弧。
- 顶部状态：“正在识别对手队伍 · 第 3/6 个位置”。
- 输入操作变为不可重复触发，提供 Quiet 类型 `取消识别`。
- 取消或失败后保留原有可用结果，说明本次结果没有应用。

### 识别完成

- 自动选中第一个已确认的对手；若我方有默认首发，同时建立当前对位。
- 使用非阻塞状态消息：“已识别 5 个位置，1 个需要确认。”
- `Review` 槽位位于普通 Tab 顺序内，Enter 打开修正抽屉。
- 截图输入折叠为标题栏中的 `重新识别`，不继续占据主栏。

### 空、失败与离线

| 场景 | 主文案 | 行动 |
|---|---|---|
| 未选我方队伍 | 选择一支队伍后即可比较速度和伤害 | 选择队伍 / 创建队伍 |
| 非选队截图 | 没有找到完整的六个对手位置 | 选择另一张截图 |
| OBS 未连接 | 尚未连接 OBS，仍可从本地图片开始 | 打开截图 / 设置 OBS |
| 部分资料缺失 | 已识别宝可梦，但部分对战资料不可用 | 查看可用资料 / 更新资料 |

## 对位结论标签

默认标签显示四个块：

1. 速度：我方 167 / 对手范围 154–189，结论“条件不足”。
2. 属性：`地面 2×`、`岩石 2×`、`毒 ½×`。
3. 威胁：采用率最高的三个伤害招式，不推断对手一定携带。
4. 推荐入口：我方四招的快速伤害范围。

详细种族值不是默认标签。普通用户首先看到判断；研究型用户可进入“属性与形态”。

## 修正槽位抽屉

- 标题写“修正对手位置 4”，同时显示原识别结果和相似度说明。
- 搜索字段有可见标签“选择正确的宝可梦”。
- Primary 为 `应用修正`，Secondary 为 `保留识别结果`。
- 应用后槽位显示铅笔图标和“已修正”，仅作用于当前对局。

## 快捷键与焦点

- 页面首次进入时，若无结果聚焦 `打开游戏截图`；有结果时聚焦阵容板。
- 阵容板使用 roving focus：Tab 进入一次，方向键移动，Enter 选择。
- 切换槽位后焦点留在槽位，不跳到详情面板。
- 打开/关闭修正抽屉后，焦点返回原槽位。

## 验收重点

- 3 秒内能找到双方阵容、当前对位和伤害计算入口。
- 识别完成后页面不再保留大型上传框。
- 用户不打开完整计算也能读到速度关系、弱点和常用威胁。
- 任何置信度不足、资料缺失或假设状态都不会显示成确定结论。
