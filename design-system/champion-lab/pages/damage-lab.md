# 伤害计算页面规范

> 继承 `../MASTER.md`。本页承载高密度专业计算，不牺牲结论可读性。

## 页面目标

让用户先获得可行动的击杀判断，再检查每条招式的范围、双方条件和完整计算细节。

## 布局

```text
┌──────────────────────────────────────────────────────────────────┐
│ 伤害计算   我方：大狃拉      对手：烈咬陆鲨      当前对局已同步 │
├──────────────────────────────┬───────────────────────────────────┤
│ 我方条件                     │ 对手条件                          │
│ 形态 / 道具 / 能力等级 / 顺风│ 形态 / 假设配置 / 能力等级 / 顺风│
├──────────────────────────────┴───────────────────────────────────┤
│ 我方打对手 | 对手打我方 | 场况与背景                           │
│ 招式        伤害范围条             百分比        击杀判断       │
│ 近身战      ━━━━━━━━━━━━━━━         88–104%       乱数击杀       │
├──────────────────────────────────────────────────────────────────┤
│ 计算说明 / 触发条件 / 随机数明细                                 │
└──────────────────────────────────────────────────────────────────┘
```

## 顶层结论

- 每行招式必须同时显示：招式名、属性、伤害区间、百分比、击杀判断。
- 默认按我方实配的四招顺序展示，不按伤害自动重排，避免用户失去肌肉记忆。
- 可通过明确的“按最高伤害排序”切换排序，返回页面时保留选择。
- `稳定击杀`、`乱数击杀`等结论旁显示计算条件摘要入口。
- 不支持的机制显示“此条件暂未纳入计算”，而不是输出看似精确的结果。

## 条件编辑

- 常用条件直接显示：双方形态、能力等级、顺风、条件特性。
- 天气、场地、威力修正等放入“更多场况”。
- 已启用条件以 chip 汇总在结果上方，允许一键清除单项。
- “仅本次假设”使用明确开关及帮助文本，不改变预存队伍。
- 修改任何条件后，结果区保留尺寸并显示“正在重新计算”，不清空为白屏。

## 伤害范围条

- 轨道高度 12px，最小/最大值两个端点可见。
- 我方造成伤害使用训练家蓝；对手造成伤害使用对手红。
- 50% 和 100% 刻度提供文本提示；不能只靠颜色表示是否击杀。
- 多段招式显示“2–5 次”条件和独立范围，不把所有组合挤入一条不可读的图。
- 表格模式可复制完整数值，详情模式解释随机数、HP 和防御假设。

## 详情区

- 点击行后在下方展开或右侧抽屉显示计算明细。
- 明细顺序：最终结论 → 双方关键能力 → 采用条件 → 随机范围 → 未支持项 → 数据版本。
- 列标题 tooltip 只是补充；所有完整配置必须能通过键盘点击打开。
- `来源 / 规则说明` 为 Quiet 按钮，不使用外链箭头作为装饰。

## 空状态与错误

| 场景 | 文案 | 行动 |
|---|---|---|
| 无我方队伍 | 选择一支预存队伍后才能使用实配数据 | 选择队伍 / 创建队伍 |
| 无对手 | 从当前对局选择对手，或手动搜索宝可梦 | 选择对手 |
| 引擎不可用 | 伤害引擎没有启动，当前资料没有丢失 | 重试 / 查看诊断 |
| 招式不支持 | 此招式包含尚未实现的伤害机制 | 查看支持范围 |

## 键盘与全屏

- `F11` 切换全屏；Esc 退出全屏或先关闭抽屉。
- 上下键移动招式行，Enter 展开详情，左右键只在明确的标签页中切换。
- 全屏与普通模式保留选中招式、滚动位置和计算条件。

## 验收重点

- 不展开详情也能判断每个招式能否一击或二击。
- 任意结果都能追溯到队伍、形态、场况和资料版本。
- 重计算期间界面不跳动、不冻结、不丢失上次可用结果。
